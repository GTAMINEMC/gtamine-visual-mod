# GTAMINE Visual

**Твой интерфейс. Твоё расположение. Твой GTAMINE.**

Мод для Minecraft, который делает игру на **GTAMINE RolePlay** удобнее

[Сайт GTAMINE](https://gtamine.com) · [Скачать с GitHub](https://github.com/GTAMINEMC/gtamine-visual-mod/releases) · [Для разработчиков](#для-разработчиков)

## Создан для GTAMINE

GTAMINE Visual дополняет серверный интерфейс: помогает перемещать HUD и мини-карту,
сохраняет твоё расположение и отмечает серверы проекта плашкой **ɢᴛᴀᴍɪɴᴇ** в списке серверов.

Установи мод, зайди на сервер и настрой расположение интерфейса под себя.

Игровые функции работают на `gtamine.com`, `gtamine.ru`, `needmine.ru`, `playgo.pro`
и адресах вроде `mc.gtamine.com`. На других серверах и в одиночной
игре эти возможности недоступны.

Для запуска нужны **Minecraft 1.21.11**, **Java 21**, **Fabric Loader 0.19.5+**
и **Fabric API 0.141.6+1.21.11** для этой версии Minecraft.

1. Установи Fabric для Minecraft 1.21.11.
2. Скачай файл мода и Fabric API.
3. Помести оба файла в папку `mods` своей игры.
4. Запусти игру, подключись к GTAMINE и прими предложенный сервером набор ресурсов.

## Автоматические обновления

Начиная с **1.0.1**, при запуске игры мод в фоне проверяет последний стабильный
релиз в GitHub Releases. Подходящий файл скачивается автоматически; уведомление
сообщит, что обновление установится после выхода из игры. При следующем запуске
будет загружена новая версия. Первую версию с обновлятором установи вручную.

Проверяются SHA-256, идентификатор и версия мода, Minecraft, Java, Fabric Loader
и необходимые моды. Несовместимые версии и предварительные релизы пропускаются.
Если GitHub недоступен, остаётся текущая версия. Обновлятор работает при запуске
независимо от подключения к серверу; игровые функции включаются только на GTAMINE.

Обновляется только обычный файл мода непосредственно в папке `mods`.
Имя установленного файла сохраняется, резервная копия имеет суффикс `.jar.bak`.
Скачивание и служебные файлы находятся в `.gtamine-visual-updates` в папке игры;
результат установки записывается там в `installer.log`. Замена выполняется
отдельным процессом Java после завершения Minecraft. При ошибке до замены
исходный файл остаётся на месте; для восстановления можно закрыть игру и
вернуть резервной копии исходное имя файла.

Для публикации обновлений создавай стабильный релиз с тегом `v1.0.2` (и далее),
прикладывай готовый `gtamine-visual-1.0.2.jar` из `build/libs`. Версия внутри
`fabric.mod.json` должна совпадать с тегом. GitHub предоставляет SHA-256 файла;
без контрольной суммы обновлятор файл не устанавливает. Fabric API и другие
зависимости автоматически не устанавливаются. Проверяется только последний
стабильный релиз: если он несовместим, установленная версия сохраняется.

## Расположи HUD по-своему

**Редактор интерфейса** позволяет перемещать элементы HUD и мини-карту
прямо во время игры. Размести их там, где тебе удобно.

- **Открой чат**, зажми нужный блок левой кнопкой мыши и перетащи его.
- **Выровняй элементы**: они притягиваются к краям и центрам экрана и соседних
  блоков, а вспомогательные линии помогают разместить всё ровно.
- **Отпусти кнопку** — расположение сохранится автоматически на твоём компьютере.
- **Верни исходный вид** кнопкой «Сбросить расположение HUD» справа внизу над
  строкой ввода чата. Она возвращает все элементы и мини-карту на исходные места.

Мини-карта перемещается вместе с рамкой и значками и скрывается при нажатии F1.

Некоторые соседние элементы перемещаются вместе. Перенос доступен для элементов,
которые выделяются при открытии чата. После обновления серверного интерфейса
может потребоваться заново расположить их.

## Для разработчиков

Любой Paper/Bukkit-плагин может определить наличие **GTAMINE Visual** через
стандартный канал **`gtamine:visual`**, без библиотек и дополнительных плагинов:

```java
boolean hasMod = player.getListeningPluginChannels().contains("gtamine:visual");
```

Мод сам объявляет канал при подключении к разрешённому серверу. Для обнаружения
сразу после подключения используйте стандартное событие Bukkit:

```java
@EventHandler
public void onRegisterChannel(PlayerRegisterChannelEvent event) {
    if (event.getChannel().equals("gtamine:visual")) {
        Player player = event.getPlayer();
        // Игрок объявил наличие GTAMINE Visual.
    }
}
```

Обработчик нужно зарегистрировать как обычный Bukkit Listener. Сразу в
`PlayerJoinEvent` канал ещё может быть не объявлен. Для уже подключённых игроков
достаточно проверки через `getListeningPluginChannels()`.

Регистрировать каналы на стороне плагина и отправлять запросы не требуется.
Проверка сообщает только наличие мода — версия и настройки не передаются.
При использовании прокси он должен пропускать объявления каналов. Объявление
является заявлением клиента и не доказывает его подлинность.
