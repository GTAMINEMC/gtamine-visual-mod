# NMinimap: независимая от шейдеров отрисовка

Серверные исходники и ресурспаки не изменяются.

NMinimap отправляет виртуальные item frame с картой и text display с маркерами
шрифта nminimap:default. Карта содержит обычные данные 128×128, включая готовые
серверные маршруты. Сигнатура [18, 4, 49] и четвёртый пиксель определяют карту:
17 — квадрат слева, 129 — квадрат справа, 67 — круг слева, 29 — круг справа.
config.glsl задаёт размер, исходное смещение, размер содержимого и рамку.
Bitmap-провайдеры font/default.json указывают PNG маркеров. Служебные пиксели
PNG задают размеры иконки. Цвет компонента кодирует положение и поворот.

## Причина конфликта

vertex_body.glsl заменяет gl_Position карты и маркеров, превращая мировые сущности
в экранный HUD. Шейдерпаки заменяют программы мирового рендера, поэтому программа
ресурспака NMinimap может не выполняться. Прежнее смещение через UV2 не устраняло
эту зависимость.

## Новый путь

- MapRendererMixin узнаёт служебную карту, получает серверные пиксели и перехватывает
  её мировую отрисовку. Обычные карты остаются ванильными.
- MinimapDisplayMixin считывает исходные компоненты text display.
- MinimapResources читает PNG при перезагрузке ресурсов, удаляя служебные пиксели.
- MinimapRaster формирует обрезку, рамку, поворот и маркеры в CPU-буфере 256×256.
  Поворот круглой карты округляется до половины градуса.
- NativeMinimapRenderer загружает результат в одну динамическую текстуру и рисует
  через RenderPipelines.GUI_TEXTURED после bossbar HUD, перед чатом.
- MinimapMarkerMixin подавляет исходные мировые глифы NMinimap.

Программа шейдера NMinimap для вывода карты больше не нужна. Нет зависимости от API
Iris/OptiFine. Не изменяются GLSL, освещение вершин, серверные пиксели, положения
сущностей и настройки загрузчика шейдеров. Это устраняет известную зависимость
от мирового core shader; конкретные сборки проверяются отдельно.

## Жизненный цикл

Перехваты действуют только на разрешённых серверах с распознанной геометрией.
F1 скрывает итоговую текстуру. Ключ сохранённой позиции совместим с прежней версией.
При отключении текстура освобождается; при перезагрузке ресурсов перечитываются
иконки. Неизвестный формат сохраняет исходную отрисовку.

Палитра и копия карты обновляются при изменении пикселей. Маркеры кешируются по
компоненту. Текстура обновляется при изменении карты, маркеров, формы или поворота;
перетаскивание не пересоздаёт её. Сигнатурные пиксели не рисуются. Для крайних
маркеров предусмотрен прозрачный запас вокруг карты.

CPU-тесты проверяют обрезку, вращение, альфу и маркеры. Отдельный Fabric client
gametest проверяет фактическую GUI/GPU-отрисовку по пикселю скриншота. Тестовый мод
не включается в распространяемый JAR.

Проверено 19.10.2026: Iris 1.10.0, Sodium 0.8.0, активный шейдерпак
Complementary Reimagined 5.9.3, Minecraft 1.21.11. Клиентский тест создал мир,
подтвердил активность шейдерпака через Iris API и проверил точный цвет пикселя
синтетической карты после GPU-отрисовки. Тест пройден. Это проверка нового
рендера, а не подключения к живому NMinimap-серверу. OptiFine отдельно не проверен.
